# НЭТИЗ — статичная вёрстка сайта для интеграции в 1С-Битрикс

## Что это
Статичные HTML-страницы сайта netizbattery.ru (промышленные аккумуляторы, B2B).
Передаются разработчику для натягивания на Битрикс. Без сборщика, без фреймворков.

## Как устроено
- `src/*.html` — исходники страниц. Только их и редактировать.
- `partials/*.html` — шапка, подвал, лид-форма, повторяющиеся блоки. Вставляются
  через `<!-- @include partials/имя.html -->`.
- `python3 build.py` — собирает `src/` + `partials/` в `*.html` в корне.
  **Корневые *.html — результат сборки, руками не править.**
- `assets/css/main.css` — единственный CSS. Токены в `:root`, дальше компоненты по
  секциям (пронумерованы в комментариях), адаптив в конце.
- `assets/js/main.js` — ваниль, только UI-поведение. Формы не трогает (их делает Битрикс).
- `ui.html` — UI-кит: все компоненты и состояния. При добавлении компонента —
  добавить его сюда же.
- `README.md` — карта «блок → компонент Битрикса», размеры картинок, брейкпоинты.
  Держать актуальным.

## Правила
- BEM: `block__element`, `block--modifier`, состояния `.is-*`. Без инлайн-стилей
  (единичные композиционные `style="margin-top:…"` допустимы).
- Новые цвета/радиусы/отступы — только через токены в `:root`. Не добавлять новых
  hex-значений в компоненты.
- Повторяющиеся элементы размечать один раз с комментарием `<!-- xxx: item ×N -->`.
- Иконки — inline SVG со `stroke="currentColor"`.
- Шрифты локально (`assets/fonts`), никаких Google Fonts.
- Картинки: указывать `width`/`height`, `loading="lazy"` ниже первого экрана.
- Брейкпоинты: 1320 / 1100 / 900 / 760 / 560 / 420 — см. README.

## Проверка после правок
```
python3 build.py
```
Открыть изменённые страницы в браузере на 1440 и 390 px. Консоль должна быть чистой.

## Публикация
Репозиторий публикуется как есть через GitHub Pages (ветка main, корень) —
собранные `*.html` в корне и есть сайт. После правок: `python3 build.py`, коммит, push.
